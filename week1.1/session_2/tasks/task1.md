| Command | Explanation |
| ---- | ----  | 
|pwd| display current folder |
|ls|list content in the current folder|
|cd directory_name|change current folder|
|cd ..|move up one directory level|
|cd ~ |move to home folder|
|mkdir directory_name |create a new folder|   
|touch filename  |create a new file|
|git status  |shows the current state of your working directory and staging area|  
|git add -A   |stages your changes| 
|git commit -m “”  |bundles changes into one commit|
|git push  |send changes back to remote Github server|
|git pull |pull the lastest code from Github to the local work space|
